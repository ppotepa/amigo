# NPR playground

Opt-in typed-Rust NPR viewer. The YAML mod selects the authored scene; geometry,
camera response, interaction, styling and tessellation live in engine/plugin code.

Suzanne rotates automatically. Controls: arrows rotate Suzanne manually, left drag orbits the camera, wheel zooms, right
drag moves the model, Shift + right drag moves it vertically, R resets the model
and Home resets the camera. Press 1 for Perspective or 2 for Orthographic.
Press 3 for Minimal Ink or 4 for Pencil Animation.
Space pauses or resumes automatic rotation.

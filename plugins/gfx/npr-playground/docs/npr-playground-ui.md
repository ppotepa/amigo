# NPR Drawing Studio

## Document and migration

One model is active at a time. Selecting another source preserves the current
preset and checkpoints a changed drawing as a model-bound Draft. Presets contain
paper, palette, ordered entries and the immutable appearances they reference.
Scene camera, model pose and playback are not preset properties.

One authored `layers` list remains authoritative. `removed_layers` records
deletions through includes and save/reload; re-adding a position clears its
removal. Old split paint/stroke documents require the explicit migration tool.
Missing appearance references and conflicting immutable definitions are errors.

## Workspace

```text
Models / Drafts / Variants | viewport | preset picker
                                    | Lines / Paints / Paper
                                    | selected entry inspector
```

The picker opens a preset directly. Unsaved entry/preset changes require an
explicit discard confirmation. There is no separate read-only selection that
can accidentally edit another active preset.

Lines and paints are added by source. Each line exposes geometric selection,
tool and local appearance settings; hatching has independent angle, cross,
density and spacing. Paints expose colour/composition and wash/granulation where
supported. Paper is pinned and has no assign/detach-brush controls.

Categories are collapsible presentation groups with spaced, indented entries.
Arrow Up/Down and Home/End move focus between visible entry buttons; Enter/Space
selects. The explicit compositing-order view shows the real interleaved stack.
Visibility, lock, duplicate, delete, reorder and Solo act on stable backend IDs.

## Editing and previews

The inline inspector owns a local draft. Debounced `PreviewLayer` actions render
the draft on the actual model with the selected presentation backend. They do
not change authored settings or history. Apply/`ReplaceLayer` is one history
operation. Cancel, Escape and connection cancellation discard the preview.
Ctrl+Enter applies an entry draft.

Reference samples above entries are generated by the backend using the same
line tessellator/material parameters on a standard straight stroke and S curve,
or a surface patch for paints. They are illustrative SVG samples, not full GPU
captures: the viewport is authoritative for paper and granulation. Vertical
panel separators support pointer dragging and Arrow/Home/End keyboard resizing
with ARIA separator state; widths are workspace-local.

“Use saved settings“ only changes the selected entry's appearance, never its
geometric source. The picker shows one current compatible template per identity
with a generated preview; existing entries keep their pinned revision internally.
The tree exposes each assigned brush as an indented preview row. Brush Lab
captures medium, application and stroke parameters, allocates a new immutable
version on the backend and pins it to the selected entry or all matching entries.
The entire operation respects locks and undoes in one step. Revision numbers are
not part of ordinary preset or brush names.

## Saving and playback

Save Drawing writes the scene sidecar. Save Preset preserves includes and embeds
referenced appearances. Save As creates a standalone preset. Camera changes mark
the drawing changed but not the preset. Drafts and Variants live in the model
panel; they remain separate from reusable presets.

Play in the top bar controls opt-in model rotation. Camera orbit remains
independent: primary drag or right drag orbits, middle drag pans and wheel zooms.
O/V select orbit/select. Ctrl+Z / Ctrl+Shift+Z undo/redo; Ctrl+S saves the drawing
after the entry draft is applied or cancelled. Panel widths persist locally.

## Renderer contract

`NprStyleLayer::extraction_style` resolves generator and tool settings before
tessellation. Prepared model topology/surface analysis is shared; entries with
different generator settings produce independent contributions. Sources and
expanded stroke memory are bounded. The renderer uses one stable `layer_id`
per contribution and composites in authored order.

Geometry cache keys include visibility, line/hatch settings and appearance
references/overrides. Compositor-only changes reuse paths and refresh diagnostics.
Build-up and Solo are snapshot-owned preview controls, not another client stack.

Native GPU, JPEG and Local RGBA are selectable under Render diagnostics.

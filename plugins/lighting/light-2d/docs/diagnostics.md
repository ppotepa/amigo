# Light 2D Diagnostics

Primary channel: `light-2d.contributions`.

## What To Trace
- Global light id, color, intensity, and runtime updates.
- Light group id, membership, color, and intensity.
- Lightmap source id, source reference, selected channel, and warnings from scene
  command handling.

Dev console diagnostics belong to the lighting plugin and should describe
lighting state before backend lightmap execution.

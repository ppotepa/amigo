# NPR visual review artifacts

The PNG files are reviewed WGPU offscreen captures at 512x512. They are not
silently regenerated by tests. `cube-512.png` uses rx=0.36, ry=0.71, seed 42,
the paused Comic Ink scene; the two `pencil-*.png` references use Pencil Study.

The regular `npr_*` app tests lock a versioned, deterministic
`NprRenderPacket::fingerprint()` before WGPU expands or rasterises it. That is
the CI contract for topology, contour planning, stroke geometry and material
attributes. It is portable across graphics drivers and makes a packet regression
actionable rather than hiding it in anti-aliased pixels.

An image comparison is an explicit art-review gate:

```powershell
$env:AMIGO_VERIFY_NPR_GOLDEN = "1"
rtk cargo test -p amigo-app npr_playground_offscreen_matches_packet_contract
rtk cargo test -p amigo-app npr_pencil_profile_uses_depth_occluders_without_color_bands
rtk cargo test -p amigo-app npr_pencil_cylinder_streamlines_match_reviewed_golden
Remove-Item Env:AMIGO_VERIFY_NPR_GOLDEN
```

To propose a new reference, capture a candidate without touching tracked files:

```powershell
$env:AMIGO_CAPTURE_NPR_GOLDEN_DIR = "target/npr-captures"
rtk cargo test -p amigo-app npr_
Remove-Item Env:AMIGO_CAPTURE_NPR_GOLDEN_DIR
```

Inspect the candidate on the target hardware, update the PNG and its packet
fingerprint in the same reviewed change, then run both the regular contract and
the explicit visual gate. Do not use an environment variable to overwrite a
reviewed reference from inside a test.

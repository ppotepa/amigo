# 1. Etap A — fundament: rejestry muszą być mutowalne po rejestracji jako service

## Problem obecny

Obecny `HandlerRegistry` ma wewnętrznie zwykły `Vec`:

```text id="vjdx9u"
crates/engine/runtime/src/handler_registry.rs

pub struct HandlerRegistry<H> {
    handlers: Vec<Arc<H>>,
}

pub fn register_arc(&mut self, handler: Arc<H>)
```

To blokuje docelowy model, bo domenowy plugin dostaje tylko:

```rust id="55ne5z"
fn register(&self, registry: &mut ServiceRegistry) -> AmigoResult<()>
```

A po zarejestrowaniu registry jako service agent musi móc zrobić:

```rust id="b480d3"
let handlers = registry.required::<RuntimeSceneCommandHandlerRegistry>()?;
handlers.register_arc(Arc::new(Sprite2dSceneCommandHandler));
```

Do tego `HandlerRegistry` musi mieć `Mutex`.

## Operacje

```text id="fju8i5"
MODIFY crates/engine/runtime/src/handler_registry.rs
MODIFY crates/engine/runtime/src/lib.rs
TEST   crates/engine/runtime/src/handler_registry.rs
CHECK  cargo check -p amigo-runtime
```

## Zmiana: `HandlerRegistry`

### MODIFY

Plik:

```text id="f23m8i"
crates/engine/runtime/src/handler_registry.rs
```

Zmień model na:

```rust id="vo4pq7"
use std::sync::{Arc, Mutex};

#[derive(Default)]
pub struct HandlerRegistry<H: ?Sized + Send + Sync + 'static> {
    handlers: Mutex<Vec<Arc<H>>>,
}

impl<H: ?Sized + Send + Sync + 'static> HandlerRegistry<H> {
    pub fn new() -> Self {
        Self {
            handlers: Mutex::new(Vec::new()),
        }
    }

    pub fn register_arc(&self, handler: Arc<H>) {
        self.handlers
            .lock()
            .expect("handler registry mutex should not be poisoned")
            .push(handler);
    }

    pub fn handlers(&self) -> Vec<Arc<H>> {
        self.handlers
            .lock()
            .expect("handler registry mutex should not be poisoned")
            .clone()
    }

    pub fn len(&self) -> usize {
        self.handlers()
            .len()
    }

    pub fn is_empty(&self) -> bool {
        self.len() == 0
    }
}
```

```rust id="6kq2ba"
use amigo_scene::SceneService;

use crate::{SpriteDrawCommand, SpriteSceneService};

pub fn extract_sprite2d_render_commands(
    scene_service: &SceneService,
    sprite_scene_service: &SpriteSceneService,
) -> Vec<SpriteDrawCommand> {
    sprite_scene_service
        .commands()
        .into_iter()
        .filter(|command| {
            scene_service
                .entity_by_name(&command.entity_name)
                .map(|entity| entity.lifecycle.visible)
                .unwrap_or(true)
        })
        .collect()
}
```

```rust id="mrqlu1"
pub fn run_phase(&self, phase: amigo_runtime::SystemPhase) -> amigo_core::AmigoResult<()> {
    let systems = self.runtime.required::<amigo_runtime::SystemRegistry>()?;
    self.begin_system_phase(phase);

    if let Err(error) = systems.run_phase(phase, &self.runtime) {
        self.mark_scheduler_error(phase, format!("system phase {phase:?} failed: {error}"));
        return Err(error);
    }

    self.complete_system_phase(phase);
    Ok(())
}
```
